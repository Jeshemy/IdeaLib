# IdeaLib prototype

A no-build HTML, CSS, and JavaScript prototype for the IdeaLib academic workspace.

## Open in IntelliJ IDEA

1. Open this folder as a project in IntelliJ IDEA.
2. Open `index.html` and use **Open in Browser** (or your browser of choice).
3. The app uses browser `localStorage` for its prototype account, subjects, tasks, events, PDFs, and preferences. Use the same browser profile to retain saved demo data.

Files:
- `index.html` — page structure
- `styles.css` — all visual styles
- `app.js` — app state, screens, and interactions

No build step or package installation is required. Google Fonts and the landing-page image load over the internet; the rest of the interface is local.
